# 🤖 AI IT Helpdesk Chatbot

An AI-powered IT support assistant that answers common IT questions,
creates support tickets, and escalates to humans when needed.

## 🎯 Goals
- Answer IT FAQs using a knowledge base (RAG)
- Create and track support tickets
- Hand off to a human agent
- Simple web chat interface

## 🛠️ Tech Stack (planned)
Python · LLM API · LangChain · ChromaDB · Streamlit · SQLite

## 🗺️ Roadmap
- [ ] Week 1: Python basics
- [ ] Week 2: APIs & first AI call
- [ ] Week 3: Chatbot + web UI
- [ ] Week 4: Knowledge base (RAG)
- [ ] Week 5: Tickets & handoff
- [ ] Week 6: Deploy & polish
